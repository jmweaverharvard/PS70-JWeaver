The Program


My introduction to programming for this class was a veritable trial by fire as I started with the code for my MVP. As detailed in my MVP page, the goal was to create a framework for displaying images from an SD card that could be iterated upon and added to in later development steps. The input involves a button which users press to active the output, an image displayed on a tft spi screen. I pulled much of the framework for the jpeg display from a github repository and edited it to accomodate the fact that the SD card and TFT display couldn't communicate simultaneously on the same channel as well as adding the buttons. The button code is fairly simple: a digital pin is attached to the output of the button so that when it is pressed down, it receives a signal which tells it to display an image from the SD card.
