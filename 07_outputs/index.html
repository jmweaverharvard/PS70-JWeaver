Goals


Going into MVP week, I decided to focus on displaying images on a screen and swap between them using buttons, as this is both the most essential function of the exhibition and also the most challenging. It involves fairly complex circuitry, many different components (including a screen, arduino, and SD card), and to my untrained humanities mind, involved programming. The focus is on developing an iterable framework that I can easily add more functions to later on: namely, the ability to add more images.


The Code

I found a lot of robust documentation for jpeg decoding and image display online and borrowed heavily from github repos hosted by XTronical. It still took a considerable amount of work to get the wiring right and resolves all of the difficulties in communication between the SD card and the screen. I found that the SD card and the display weren't able to communicate properly if they were on the same channel of the Arduino, a fact I only discovered after substantial debugging time and the help of Bobby (thanks Bobby). I modified the code I pulled to work on different channels, fit with my specific board, and then integrated the button inputs.


The Product


At last, the screen is working! I can easily swap between images and add more using the remaining 6 pins on my arduino dev board. I also prototyped an enclosure which houses the screen at the front alongside several buttons to swap between images. Going forward, however, I'm interested in instead placing the buttons in front of where the sculptures would be in the cave temple.
